# 本地 v1.9：命名方案库与分享

v1.7.1 修复草稿和保存问题，v1.8 增加画布编辑，v1.9 在此基础上加入独立方案库。三个标签及单文件 HTML 分别保留。当前入口为 `dist/versions/field-route-painter-v1.9.html`。

## 保存和分享

1. 在画布中规划两辆车，应用需要的坐标和曲线参数。
2. 展开“保存与分享”里的“方案库”，填写名称、备注，点击“另存为新方案”。如果要覆盖所选方案，使用“用当前画布更新所选方案”。画布后续修改不会自动覆盖库内的方案。
3. 选择一个方案点击“导出所选方案”，或点击“导出整库”。发送生成的 `.route-library.json` 文件给队友。
4. 队友打开 v1.9，展开方案库，点击“导入方案／方案库”，选择文件。再选择方案并点击“载入所选方案”，即可查看和继续编辑。

单条文件与整库文件使用同一种库格式；单条文件含一个方案，整库含所有方案。每个方案包含名称、备注、保存日期、两车全局坐标、直线 / 贝塞尔段、控制点（包括直线的缓存）、阵营与坐标系等显示设置。控制点显隐尊重当前使用者选择。

导入先检查整个文件，再一次性合并。完全相同的方案跳过；同名或标识冲突但内容不同的方案作为独立副本保留，列表会注明同名序号。重复导入同一文件不会反复增加相同方案。库导入不改变当前画布，载入所选方案才会切换画布。原有 v1.6 路线 JSON 也可导入库中，默认名称为“导入的路线”。

原有“导出路线文件”继续分享当前画布；“导出带路线 HTML”只包含当前双车画布，不内置整库，也会清除本机库名称、备注等界面残留。整库分享请使用独立 JSON 文件。本功能通过文件传递，不实时同步、不会自动合并路线点。

## 编辑和撤销

- 画布上方选择“编辑模式”，点击选中当前车的路径点，拖动后松开即可保存，也会载入右侧坐标表单。空白处点击不加点。控制点须先在“路线段”中勾选显示，才可以拖动 C1/C2。
- 每次完整拖动只记一步撤销；按 Escape 或取消手势放弃预览。切换车、修改路线等外部变化会取消进行中的拖动。位置限制在场地内。
- 选择非末点，点击“在选中点后插入”，在下一段中点添加路径点；曲线用 De Casteljau 拆分为两段，保留原形。然后可拖动或输入坐标修改新点。
- 可删除任意选中点；删除中间点会将相邻两段合并为直线。画布有焦点时 Delete 也可删除选中点，输入框内按键不受影响。
- 顶部“撤销上一步”回退画布操作（最多100步），包括拖动、插删、载入方案。库内“撤销方案库操作”独立回退新建、更新、删除、合并导入（最多20步）。历史仅本次打开期间有效，不随文件导出。

## 保存保护和限制

画布自动保存和方案库分别存于当前浏览器。共享存储的旧窗口检测到新记录后拒绝覆盖；支持 Web Locks 的浏览器还会串行处理同源窗口写入。当前画布有冲突时可先导出备份，再刷新载入最新记录。关闭窗口不重复回写旧画布；请关闭仍使用旧版代码的规划窗口。库的存储检查或写入失败时，列表和旧记录保留，不会显示为保存成功。

画布两车合计最多5000点，状态入口拒绝超限操作；临时保存失败会在后续操作中重试。库最多100个方案、合计50000点，导入文件最多10 MB，每条路线仍限5000点。浏览器实际存储配额可能更小，失败时页面提示备份。重要方案应导出文件，浏览器记录不是跨设备备份。
