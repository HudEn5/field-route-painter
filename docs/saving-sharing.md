# 本地 v1.6：保存与分享

基于 `v1.5`，保存对象是当前阵营两辆车的完整规划：全局路径点、每段直线 / 贝塞尔类型、C1/C2（包括直线状态下的已保存控制点缓存）、阵营、坐标系、当前车辆和显示设置。只保存已添加的路径点和已应用的参数。

v1.7 沿用相同路线格式，可导入 v1.6 的路线文件。画布上的控制点每次打开默认隐藏，导入或撤销导入时保留当前使用者的显隐选择；这不影响控制点坐标及曲线本身。撤销历史不写入路线文件或本机保存。

## 发给组员继续修改

1. 点击“导出路线文件”，把下载的 JSON 文件发送给组员。
2. 组员用 v1.6 或兼容版本打开画板，点击“导入路线”选择该文件。
3. 两辆车的路线及曲线完整恢复，可以继续编辑，再导出文件发回。

导入会替换当前两辆车的规划；可点击“撤销本次导入”恢复导入前状态。错误文件会被拒绝，不部分导入、不改动当前路线。本版是文件传递，不自动合并多人修改，也不实时同步。

## 发给别人直接查看

点击“导出带路线 HTML”，把下载的 HTML 文件发送给对方。它包含画板代码、样式和路线数据，不依赖其他资源文件。接收方可双击查看并继续编辑。编辑结果要再次分享时，需要重新导出；自动保存不会改写磁盘上的原 HTML。

建议从 `dist/versions/field-route-painter-v1.6.html` 使用此功能。HTTP 开发预览也能将本地脚本、样式内联；直接用 `file://` 打开多文件源码 `index.html` 时，浏览器可能阻止读取源码资源，届时页面会提示改用打包后的版本文件。路线 JSON 导入 / 导出不依赖这些资源读取。

## 本机自动保存

每次已应用的规划或显示设置变化后，同步保存到当前浏览器的 localStorage；刷新、重开时恢复。重要路线仍应导出文件备份，本机记录不等于云端备份。

每份导出的 HTML 带独立文档标识，使用自己的本机保存空间。首次打开读取文件内的路线；此后优先恢复接收方在本机的修改，不覆盖其普通工作区。不同浏览器、不同存储环境不自动共享记录。

浏览器存储不可用、空间不足或记录损坏时会显示提示，仍可导出文件；损坏记录不自动覆盖，导入有效备份后可重新启用自动保存。

## 数据接口

- `src/plans.js`：格式版本 `schemaVersion: 1`，场地标识 `vexu-override-2026-27-preview1`，名义边长 3657.6 mm，存储单位 `logical-1000`。相对坐标只作为显示设置，导入不做二次缩放。
- JSON 上限 5 MB，两车合计最多 5000 个路径点。导入检查场地、单位、有限坐标、范围、段数、曲线控制点和显示设置，只保留已定义字段。
- `store.replacePlan(plan)` 在完整候选状态通过验证后，一次性发布新状态。
- 内置 JSON 用转义文本保存，不作为脚本执行；分享 HTML 的运行脚本与样式全部内联。
- 本机键为 `route-painter:plan:v1:<documentId>`；普通工作区使用 `workspace`，每次导出 HTML 创建新的文档标识。
