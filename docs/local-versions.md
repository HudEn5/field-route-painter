# 本地版本索引

每个版本用本地带说明的 Git 标签固定，后续修改使用独立分支。版本标签不移动；小调整增加补丁号，功能升级增加次版本号。这些标签不自动推送到 GitHub。

| 版本 | 基于 | 内容 |
| --- | --- | --- |
| v1.0.0 | 原始项目 | 已交付的基础画板 |
| v1.1 | v1.0.0 后续代码 | VEX U 场地、毫米坐标 |
| v1.2 | v1.1 | 双车独立路线 |
| v1.3 | v1.2 | 全局 / 相对首点坐标切换 |
| v1.3.1 | v1.3 | 点号简化为 1、2、3… |
| v1.4 | v1.3.1 | 输入毫米坐标新增点、修改已有点 |

查看版本：`git tag --list`；查看某版：`git show v1.3.1`。准备下一项优化时，先确定基于哪个版本，再从该标签创建功能分支。

## 直接打开旧版效果

在当前分支的项目根目录运行 `node scripts/export-version.mjs v1.2`，得到 `dist/versions/field-route-painter-v1.2.html`，双击即可打开。把版本号换为表内其他标签，可单独导出各版，不用切换分支或覆盖当前源码。

导出文件来自该标签的源码，标题附版本号，不包含后续功能。`dist/` 为本地生成产物，不纳入 Git。新版本记录了功能检查，另行进行双击、断网测试后才能记为通过。
