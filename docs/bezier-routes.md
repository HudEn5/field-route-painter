# 本地 v1.5：可选贝塞尔曲线

基于 `v1.4`，每对相邻路径点构成一个路线段。端点仍由原有坐标表单或画布点击确定，默认全部为直线；同一辆车的路线可混合直线与曲线。

## 使用

1. 在“路径点”中至少建立两个点，确定起点和终点。
2. 切换右侧“路线段”，选择要修改的点对。
3. 本段类型选择“三次贝塞尔曲线”，输入 C1、C2 的四个毫米坐标，点击“应用到本段”。曲线经过起终点，不要求经过控制点。
4. 可随时选择“直线”并应用；之前保存的控制点会保留，下次切回曲线时自动载入。

控制点跟随当前车辆及全局 / 相对首点坐标系。相对坐标始终相对当前车第一个路径点，不是每段起点；切换坐标系仅改变读数。默认控制点位于端点连线的三分之一、三分之二处，需要调整坐标才能看到明显弯曲。

本版要求控制点位于场地内，拒绝空值、非有限值及换算后越界的输入。黄色辅助线及 C1/C2 标记只用于编辑，不属于路线。v1.7 默认隐藏，需要时在“路线段”中勾选“显示当前段控制点”；隐藏后仍保留曲线形状和参数。

## 数据和行为

- `routes` 保留每辆车的全局逻辑路径点；`segmentRoutes` 保存每辆车的路线段。当前车分别通过 `points` 和 `segments` 读取。
- 新段默认 `{ type: "line" }`；曲线为 `{ type: "bezier", c1: { x, y }, c2: { x, y } }`。切回直线时可保留 c1/c2 缓存。
- 通过 `store.setState({ segments })` 更新当前车，数量必须为 `max(0, points.length - 1)`。路线段及控制点为只读快照。
- `selectedSegment` 选择当前编辑段；`showControlPoints` 决定辅助线显隐。切车后选择该车第一段，无段时为 null。
- “删除最后一点”同步删除对应路线段，清空只影响当前车；之后新增的段为直线。v1.7 的“撤销上一步”可恢复删除或清空前的点和完整曲线参数，也可撤回曲线类型或控制点修改。
- 移动端点时，控制点保持原全局位置，曲线相应改变。不同段之间不自动保证切向连续，用户需自行调整控制点。
- 路线长度包含直线段和贝塞尔弧长，采用递归二分的自适应近似，页面标为“约”；不做车辆运动学、障碍碰撞或可行驶性判断。
- 配色或辅助线显隐不会清掉尚未应用的控制点输入；切换车辆、段或坐标系会载入对应的已保存参数。
