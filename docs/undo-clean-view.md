# 本地 v1.7：撤销与显示

基于 v1.6，保留此前各本地版本。构建结果为 `dist/versions/field-route-painter-v1.7.html`。

## 三项调整

- 路线主线宽由 6 缩至 3，白色衬线由 11 缩至 6；圆点半径由 9 缩至 5，方点边长由 18 缩至 10，编号字号由 19 缩至 14。数值为 1000 × 1000 画布逻辑单位，显示时随画布缩放。两车仍使用实线圆点、虚线方点区分。
- “撤销上一步”回退最近一次已应用的路线操作，包括新增点、修改坐标、删除末点、清空当前车、修改曲线类型或控制点、导入规划。单独保留“删除最后一点”。清空后撤销会完整恢复路径点及曲线数据。
- C1/C2 和黄色控制辅助线默认隐藏。在右侧“路线段”中勾选“显示当前段控制点”，仅显示当前选中曲线段的控制点，取消勾选即可隐藏。切回直线时也不画控制点，曲线参数继续保存。

## 撤销范围

历史按两辆车的实际操作顺序保留，最多 100 步，仅限本次打开期间。跨车撤销会自动切回被操作的车；阵营、坐标系、坐标显隐、控制点显隐和段选择不占用历史。普通路线操作撤销时保留当前显示选择；撤销导入会恢复导入前的双车规划、车辆与坐标系等设置，但保留当前控制点显隐选择。

无数据变化或无效输入不占用历史。撤销结果会自动保存；刷新或重开时以恢复的规划为起点，撤销历史清空。路线 JSON 和带路线 HTML 不携带撤销历史。没有重做功能。

控制点每次打开默认隐藏，包括自动恢复旧规划及打开带路线 HTML。导入旧路线文件不会强制显示控制点；隐藏只影响画布辅助标记，不改变曲线坐标或长度。
